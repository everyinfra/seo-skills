# 竞品与外链发现(种子站 → 谁链谁 → 互换 → 外联候选 → 竞品 SEO 底账)

## 用途

回答五个问题:
1. 我们这个品类的上下游有哪些站(代理 IP、指纹浏览器、验证码、爬虫 API、AI 智能体工具……)?
2. 这些站各自被谁链接?
3. 谁和谁互换过外链?这些站大概率还会再换;它们合作页上列着的站,也是会换的站。
4. 哪些站链了好几家同行,却没链我们?这些是外联的第一批对象。
5. 竞品排在哪些词上、靠哪类页面拿到排名?我们针对性复制什么?

没有 Ahrefs / Semrush 也能做。脚本:`scripts/link_intel.py`(stdlib,子命令见文件头)。有付费工具导出时,用 `backlink_import.py` 吃进来,和这里的结果互相补。

## 数据源和局限

| 要的东西 | 免费来源 | 局限 |
|---|---|---|
| 种子站 | search MCP 搜榜单文章(best X、top X providers、X alternatives、X 推荐、X 哪个好),数每个站出现在几篇里 | 榜单偏英文;中文「验证码」查询会混进接码平台,要分清 |
| 任意域名的入链域 | Common Crawl 域名级链接图(commoncrawl.org/web-graphs,每季度一版,顶点约 1GB、边约 8GB 压缩) | 只到域名级,没有页面和锚文本;边不只来自正文里的 `<a>`,还有 `<link>`、`<script>`、og:image、跳转和 robots.txt 的 Sitemap 行,不看 rel、不分正文和页脚(cc-pyspark `wat_extract_links.py` 的 `ExtractHostLinksJob`,https://github.com/commoncrawl/cc-pyspark ,核对 2026-11-06),所以「链了」不等于「推荐了」,双向边也不等于互换;只到该季度;Common Crawl 抓得少的站入链偏少。高峰时 S3 整桶回 503 SlowDown(不是按 IP 封,换 IP 没用),脚本按 16MB 分段顺序取、失败换地址重试;整天都限流时换个时段再跑 |
| 域名权重的替代 | 同一版的 harmonic centrality 名次(`--ranks`,再下 2.3GB) | 名次是全网图上的中心度,不是流量 |
| 互换的页面证据 | 自己抓合作 / 集成 / 友链 / 资源页,以及路径里带对方品牌词的页(评测、合作方介绍、客座文章) | 只看静态 HTML;要 JS 渲染的页面认不出 |
| 竞品排名 | search MCP 的 SERP 抽样(一词一次,前 10 名) | 一天的快照,只是抽样 |

另一个免费来源:Bing 站长工具「外链 → 类似网站(Similar sites)」页签,能看别家站的入链(引用页和锚文本,可导出)。它只能在网页上登录后用,API 里没有,导出后可以交给 `backlink_import.py`。适合在链接图圈出候选之后,对重点竞品补页面级证据。来源:https://www.bing.com/webmasters/help/backlinks-c3a334e8

## 流程

1. **种子站**:每个类别写 6–8 条英文、3–4 条本地语言的榜单意图查询,用 search MCP 取前 10 名,标出哪些是榜单 / 对比文章,存成 `listicles.json`(格式见 `link_intel.py` 文件头)。然后跑 `link_intel.py listicles --input listicles.json --min 2`,出现在 ≥2 篇榜单里的站进种子名单。再补上已知的直接竞品、已有的合作方和 SERP 抽样里的常客。
   - 榜单文章本身就是「求收录」外联对象:作者会更新榜单,把我们写进去比换链接更有用。
2. **谁链谁**:跑 `link_intel.py ccgraph --targets seeds.txt --own 我们的域名 --ranks --out graph.json`。一次能查几百个目标域,瓶颈是下载约 9GB(20MB/s 时约 10 分钟),不落盘。
3. **互换**:有两个来源。
   - 链接图里目标域之间的双向边:`graph.json` 的 `mutual` 字段。
   - 页面级:跑 `link_intel.py crawl --sites 名单 --own 我们的域名 --out crawl.json`,两边各给一个页面。合作页、友链页上的互链,基本就是换过的。
4. **互换池**(找「会换链接的站」,量最大):跑 `link_intel.py exchangers --crawl crawl.json --own 我们的域名 --ledger 已联系.csv --out pool.csv`。
   - `role=host`:自己有合作 / 友链 / 集成页、上面列了 ≥3 个外站的站。它们已经在做互换,是第一批。
   - `role=listed`:这些页上列着的外站,`count` 是被几家列出。被代理、指纹浏览器、验证码站同时列着的,最可能也愿意换。
   - 这里只看「会不会换」,不看页面主题:代理站、指纹浏览器站和卖数据 API 的我们主题不同,照样能互挂合作页。
   - 拿到池子先分类(代理、指纹浏览器、验证码、接码、爬虫 / 数据、AI、跨境电商、营销、自动化、灰色),去掉 cloaking、卖号、刷量这类灰色站和打不开的站,再按「被几家列出」排。
   - 2026-11-06 在 everyinfra.com 上:196 个种子站里 57 个有合作页,页上列出外站 1,262 个,被 ≥2 家列出、没联系过的 462 个。人工核实过的互换伙伴里,自己有合作页的 5 家全部认成 host,并标出已链我们。
5. **求收录候选**(榜单、资源页):跑 `link_intel.py intersect --graph graph.json --crawl crawl.json --listicles listicles_out.json --seeds seeds.txt --min 2 --ledger 已联系.csv --out candidates.csv`(链接图下不来时去掉 `--graph`,只用页面证据)。
   - 种子名单先过一遍:只留同类和相邻的厂商、服务(代理、指纹浏览器、验证码、爬虫 / 数据 API、搜索 API、AI 智能体工具)。论文、法规、标准、开源库文档、预约和表单组件、通用 SaaS 不算种子,脚本按平台名单自动去掉一批,剩下的人工删。
   - 只算正文里的链接:导航、页头、页脚、侧栏里的不算推荐(页脚里的姊妹站、页头的「预约演示」会把厂商自己顶成候选)。互换识别不受影响,页脚互链照样算。
   - `followed` 列是「至少有一条 follow 链接的种子数」;榜单里同行链接常是 nofollow,它仍是「求收录」对象,只是外链价值低一档。
   - 两种证据分开判:抓过页面的域(`--crawl`、`--listicles` 里有它的页)只按页面判,链接图里它链了几个种子另记在 `graph_seeds`,不参与判断;只在链接图里出现的域 `followed` 留空(链接图没有 rel)、`evidence_kind=commoncrawl`,排在有页面证据的行后面,用前先抓页核实。
   - 然后逐个判断(人或模型都行,看首页和链了种子的那几页):是不是直接竞品;那几页的主题我们放不放得进去(讲云浏览器、指纹浏览器、代理的榜单,卖数据 API 的放不进去);是不是垃圾站;有没有现实途径放我们的链接。只把「值得联系」的交给外联。
   - 一次抓几百个站时,`crawl` 先抓路径带我们品牌词的页,再抓合作类页,最后才是带别家品牌词的页;否则别家品牌词的博客会把页数上限占满,给我们的那页抓不到。
6. **竞品 SEO 底账**:按我们的产品面组 60–100 个词,覆盖平台词、品类词、替代 / 对比词和本地语言词,用 search MCP 抽 SERP,存成 `serp.json`。跑 `link_intel.py footprint --serp serp.json --own 我们的域名`,看三样:
   - 每家竞品排在哪些词上;
   - 它们靠哪类页面拿到排名(对比页、博客、文档、免费工具、平台落地页、术语表、集成页、应用市场);
   - 我们缺位的词,按赢家页面类型归组。哪类页面赢的词最多,就先复制哪类。

7. **顺手两件**:
   - 失效链接替换:`link_intel.py deadlinks --input 榜单或资源页清单`,列出页上指向 404、410 或已经连不上的站的链接。对方要换掉死链,正好给他我们的同类页。
   - 未链接的品牌提及:search MCP 搜品牌名(排除自己的域名),把结果网址交给 `link_intel.py unlinked --own 我们的域名 --brand '品牌正则'`,列出提到我们却没链我们的页,附上下文。

## 拿到候选之后

- 走现有的外联流程,一家一封,写清双方各放在哪里,不批量。跟踪用 `outreach_tracker.py`,或项目自己的台账。
- 不要只为互链建合作页,也不要「三角互换」。Google 垃圾内容政策把「过度互换链接」和「只为交叉链接设的合作页」算作链接作弊。真有合作关系(集成、联名教程、对方真在用我们)再互挂。
- 对方链到竞品的那一页,如果是榜单或资源页:先确认我们有同等或更好的东西可以放进去,再联系。没有就先补内容。
- 竞品的平台落地页、对比页赢词最多时,复制的是「页面类型和结构」(一个平台一页、带价格和示例响应、对比表),不是抄内容。对比页怎么写见 [competitor-page-patterns](competitor-page-patterns.md)。

## 判据(复用时按这个验)

- 链接图读取:`tests/test_link_intel.py` 用手搭的小图验证入链、互链、名次和候选,期望值按图的定义数出来。
- 互换识别:找一份人工核实过的互换记录当对照(例如运营台里对方回链状态是 present 的合作方),页面级识别应能找回其中的静态页面。2026-11-06 在 everyinfra.com 上的实测结果见 CHANGELOG。
- 候选质量:从「值得联系」名单前 40 个里随机抽 20 个,由没看过脚本和判断过程的人或代理打开核对:「正文里真链了 ≥2 个所列种子」应 ≥80%,「值得联系」应 ≥70%。只看脚本输出、不做第 4 步的判断时,2026-11-06 实测链接属实 85%、值得联系只有 30%(引用链接、页脚、直接竞品、品类不对);所以第 4 步的判断不能省。
