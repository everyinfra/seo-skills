# 外链画像分析框架

> 建立于 2026-10-09。框架要点参考 [AgriciDaniel/claude-seo](https://github.com/AgriciDaniel/claude-seo)（MIT）的 `seo-backlinks` 技能与 [zubair-tradzada/dataforseo-claude](https://github.com/zubair-trzada/dataforseo-claude) 的层级式数据源选择，按本套件的证据约束改写。
> 本文件是分析框架，不是数据服务：所有数据来自你自己的工具导出或 API 账号。不承诺外链数量、排名或流量的提升。

## 一、开始前：数据源检测级联

先探测可用数据源，再决定分析深度。层级从高到低：

| 层级 | 数据源 | 成本 | 能提供 | 置信度参考 |
|---|---|---|---|---|
| 3 | DataForSEO 等付费 API | 按调用计费 | 全量外链、锚文本、增减速度 | 1.00 |
| 2 | Moz API（免费注册）、Bing Webmaster（免费） | 免费 | DA/PA/Spam Score、已验证属性的链接 | 0.85 / 0.70 |
| 1 | Keywords Everywhere（免费注册） | 免费 | 域名排名与来链域数（时点） | 0.60 |
| 0 | Common Crawl 域名图 | 永远可用 | 域名级 PageRank、谐波中心性 | 0.50 |
| 0 | 自建验证爬虫 | 永远可用 | 已知外链是否仍然存在 | 0.95 |

规则：

- **多个源都有数据时按置信度加权合成**：`加权分 = Σ(源分 × 置信度 × 因子权重) / Σ(置信度 × 因子权重)`。
- 两个源冲突时**相信更高层级，但把分歧写进报告**，不悄悄择一。
- 免费源要明确标注"仅时点快照"——Common Crawl 的索引有数月滞后，不能当速度数据用。
- 没有任何付费/注册源时，仍可基于 Common Crawl 出域名级报告，并附一句建议："配置免费 Moz / Bing API 可获得锚文本与页面级数据"。

## 二、七段式分析结构

每段列出该段要看什么、判什么、数据从哪来。

### 1. 画像总览

总量指标：外链总数、来链域数、follow 比、趋势。判读参考（非硬规则）：

- 来链域数：>100 良好 / 20–100 观察 / <20 薄弱。
- follow 比：>60% 正常 / 40–60% 观察 / <40% 偏低。
- 集中度：单一域贡献 >25% 来链域总数时标记集中风险。
- 趋势：季度降幅 >20% 视为快速流失，需要查明原因。

### 2. 锚文本分布

健康区间参考（通用基线，行业有偏移，见下）：

| 锚类型 | 健康区间 | 过度信号 |
|---|---|---|
| 品牌词 / 品牌+URL | 30–50% | — |
| 裸 URL | 15–25% | — |
| 通用词（click here 等） | 10–20% | — |
| 精确匹配关键词 | 3–10% | >15% 过度优化 |
| 部分匹配 | 5–15% | >25% 标记 |

行业偏移：SaaS 品牌词常见 40–55%；本地服务 45–60%；出版/媒体 30–40%。精确匹配锚在单域内 100% 集中时按高危处理。

### 3. 来链域名质量

- TLD 分布：.edu / .gov / .org 通常高价值；.xyz / .info 占比过高是低质信号。
- 国家分布：80% 以上来自与业务无关的国家 → PBN 信号之一。
- 权威分层：来链域按 DA（或等价指标）分桶（<20 / 20–40 / 40–60 / 60+），看分布形态而非单个高值。
- 每域的 follow/nofollow 比。

### 4. 毒链检测

**高危（发现即标记）**：PBN 网络；单域 100% 精确匹配锚；被惩罚或除名域；批量目录（50+）；链农场（单页出链 10K+）；付费全站页脚/侧栏模式。
**中危（组合出现时标记）**：无关利基；明显互链模式；薄内容站（单页 <100 词）；单域 >50 条来链。

完整的 30 模式清单见源仓库 `skills/seo/references/backlink-quality.md`（链接在文末）。

### 5. 按外链排序的页面（链磁铁）

三类页面值得单列：

- **链磁铁**：自然吸引链接的页面——内容策略的正面证据。
- **零外链重要页**：需要内链把权重传导过去。
- **带外链的 404 / 301 链**：**链权回收机会**——修复或重定向可收回既有关注度。

### 6. 竞品差距

矩阵：链接到竞品但不链到目标站的域 = 机会；双向 = 关系验证；仅链目标站 = 竞争优势。输出 Top 20 机会域附权威值。

### 7. 新增与丢失

- 需要 DataForSEO 级数据；免费源明确标注"无法提供"。
- 红旗：一周内新增 10 倍于常态（负 SEO 嫌疑）；一月丢失 50%+（惩罚嫌疑）；新增全部来自同一 TLD 或国家；连续 3 个月速度下滑。

## 三、外链健康分（0–100）

| 因子 | 权重 |
|---|---|
| 来链域数 | 20% |
| 域质量分布 | 20% |
| 锚自然度 | 15% |
| 毒链占比 | 20% |
| 速度 | 10% |
| follow/nofollow | 5% |
| 地理相关性 | 10% |

**数据闸门（强制）**：7 个因子里 ≥4 个有真实数据才允许输出数字分；否则必须输出 `外链健康分：数据不足（X/7 因子已评）`，并把缺失因子与补齐方式写明。**禁止对未测量的因子赋默认数值**——缺数据的数字分比没有分数更误导。

## 四、Disavow 决策

**应该 disavow**：收到人工惩罚；有明确负 SEO 证据；毒链占比 >10%；确认的 PBN 或链农场。
**不应该 disavavow**：Google 大概率已自动忽略的链接；nofollow 链接；合法的低权威站；垃圾链接 <2% 的档案。
文件格式：每行 `domain:` 前缀 + 带日期的头部注释。disavow 是最后手段，不是日常清理工具。
