# 外链渠道目录（分级+验证日期）

> 建立于 2026-10-09。渠道收录与格式参考 [flaqai/backlink_skills](https://github.com/flaqai/backlink_skills)（中文，753★）、[alvinunreal/awesome-submitlist](https://github.com/alvinunreal/awesome-submitlist)（155★，339 目的地）、[indie-hacking/Awesome-SEO-Backlinks](https://github.com/indie-hacking/Awesome-SEO-Backlinks)（137★，双语）。**本文件的差异化：每条渠道带"最后核验日期"——市面上所有同类目录的通病是陈旧（indie-hacking 的流量数据冻结在 2024-02），持续核活是本套件的方法论。**
> 提交纪律：不群发。执行前重访该站核对当前条款（收费/收录规则可能已变）。不承诺收录、Dofollow 或排名。

## 一、条目格式

| 字段 | 说明 |

| 成本 | Free / Paid |

| 权威参考 | DR 或 AS 数值，标注"会漂移，使用前自行复核" |
| 最后核验 | 本目录维护者的最近一次人工核验日期 |

## 三、开发/内容平台（有实质内容时才做）

- **GitHub**（README/Profile/Docs 链接，dofollow）：开源项目是最高性价比的品牌外链
- **npm / PyPI**（包页主页链接）
- **Medium / Dev.to / 知乎专栏 / 微信公众号**：内容分发+个人页链接
- **YouTube 频道关于页**：Gemini/ChatGPT 偏好的引用源（品牌权威权重最高的平台）

## 四、核验纪律（本目录的维护规则）

1. **六字段数据溯源**（借自 flaqai）：任何流量/权威数字记录 `数据源/指标/统计月份/地域/设备/核验日期`——无源数字不收录。
2. **季度抽样复核**：每季度抽 10% 渠道重访，死站移入归档区并注明日期。
3. **执行前复核**：使用任何渠道前重访其当前条款——目录站的收费/规则可能已变，本目录的核验日期是最近一次维护核验，不保证你访问时仍准确。
4. **反群发**：单批 ≤10 个渠道，按类型分层投放，逐渠道记录结果。

## 五、提交结果度量（反虚荣 KPI）

用：合格发布率、引荐访问、引荐转化、档案准确率、收录存活率。
**不用**：提交数、外链数、dofollow 数、DA/DR（参考 [flaqai v2-quality](https://github.com/flaqai/backlink_skills) 的 KPI 规则）。
