# 程序化 SEO 质量闸门

> 建立于 2026-10-09。阈值参考 [AgriciDaniel/claude-seo](https://github.com/AgriciDaniel/claude-seo)（MIT）`skills/seo-programmatic/SKILL.md` 与 `skills/seo/references/quality-gates.md`。按本套件证据约束改写。
> 背景：Google 的 scaled-content-abuse 政策针对"大量无独立价值页"，这些闸门是风险控制，不是流量保证。

## 一、核心闸门（数字硬规则）

| 指标 | 阈值 | 动作 |
|---|---|---|
| 未复核页 | **100+** | WARNING：发布前须内容审计 |
| 无正当理由页 | **500+** | **硬停**：需用户明确批准 + 薄内容审计 |
| 页间唯一内容 | **<40%** | 标记薄内容（惩罚风险） |
| 页间唯一内容 | **<30%** | 硬停（增强规则） |
| 单页字数 | <300 | 标记复核 |
| 近重复记录 | 字段重合 >80% | 标记 |

唯一度计算：`(该页独有词 / 该页总词) × 100`，对照集内全部其他页；公共头脚导航排除，模板样板计入。

## 二、发布纪律

- 人工抽检 **≥5–10%** 样本
- 分批上线：每批 **50–100 页**，观察 **2–4 周**再下一批
- **绝不一次性发布 500+ 未审页**

## 三、页型地板（字数/唯一度）

| 页型 | 字数下限 | 唯一度下限 |
|---|---|---|
| 主页 | 500 | 100% |
| 服务页 | 800 | 100% |
| 位置页（主） | 600 | 60% |
| 位置页（次） | 500 | 40% |
| 博客 | 1,500 | 100% |
| 产品页 | 400 | 80% |
| 分类页 | 400 | 100% |
| About / 落地页 | 400–600 | 100% |

位置页专则：**30+ WARNING**（强制 60%+ 唯一）、**50+ 硬停**（需正当理由）。"换城测试"：换掉城市名内容仍成立的页是 doorway。

## 四、安全 vs 风险页型

**安全（可规模化）**：集成页（真实设置文档+API 细节+截图）、模板/工具页（可下载）、词表（200+ 词定义）、产品页（独特规格/评论/对比）、数据页（独有统计/图表）。
**风险（惩罚候选）**：仅换城市的地点页、无行业价值的 "Best [tool] for [industry]"、无对比数据的 "[竞品] alternative"、未审 AI 生成内容、**模板样板 >60%** 的页。

## 五、URL 与内链规则

- 小写连字符 slug；生成时强制唯一；**<100 字符**；主内容 URL 不带 query 参数；尾斜杠一致
- 内链 3–5 条/千词；自动关联 3–5 个相关页；hub/spoke 结构配 BreadcrumbList
- Sitemap 在 **50,000 URL / 50MB** 拆分（先到先拆）；`<lastmod>` 用数据更新时间戳；noindex 页不入 sitemap

## 六、索引膨胀控制

- 未过闸门的页 noindex
- 仅真重复/低价值筛选视图做 noindex/canonical 合并
- **>10k** 程序化页的站监控抓取统计
- 月度"已索引 vs 应索引"审计
- 薄记录合并入聚合页
