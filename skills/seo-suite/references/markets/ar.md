## 三、语言机制(RTL 是硬检查)

### 3.1 RTL 全链

W3C 国际化文档([Structural markup and right-to-left text in HTML](https://www.w3.org/International/questions/qa-html-dir),读取 2026-10-21)的要点:
- 整页是 RTL 时,在 `<html>` 加 `dir="rtl"`。
- 不要用 CSS 设置基础方向。边距、内边距、对齐用逻辑属性(`margin-inline-start`、`padding-inline-end`、`text-align: start`)。
- 避免写死 `left`、`right` 的 HTML 属性值。
- 表单和运行时插入的文本用 `dir="auto"`。

本套件在此之上加两条:图标、箭头、进度条、面包屑分隔符要镜像;三者缺一就会出现「半翻转」页面。
- hreflang:`ar` 是合法语言码。内容按国家区分时再加 `ar-SA`、`ar-AE`、`ar-EG`(ISO 639-1 + ISO 3166-1 Alpha-2,[Google 文档](https://developers.google.com/search/docs/specialty/international/localized-versions))。旧稿「只挂 ar 不挂国码=自弃分层」说重了:只有各国版本内容不同时才需要国码。

### 3.2 双向文本隔离

- 裸 LTR 的标点、数字、品牌名放在 RTL 句子里会乱序。
- W3C 的建议顺序:先用**标记**。已知方向的短语用 `<span dir="ltr">`;不知方向的用 `dir="auto"` 或 `<bdi>`([Inline markup and bidirectional text in HTML](https://www.w3.org/International/articles/inline-bidi-markup/))。
- 只有无法用标记的地方(例如 `<title>` 文本)才用 Unicode 隔离字符:U+2066 LRI 或 U+2067 RLI 开头,U+2069 PDI 结尾。W3C 说明优先用标记,因为更易管理。
- 常出错的内容:英文括号、价格(混合币种符号)、SKU、电话(+966)。

### 3.3 MSA 与方言矩阵

| 品类/场景 | 语域 | 备注 |
|---|---|---|
| 金融/法律/B2B/健康权威内容 | MSA | 本套件口径;LLM 在 MSA 上表现更好(见 4.4) |
| 电商/娱乐/社交内容 | 方言(海湾/埃及) | 本套件口径 |
| 兜底 | 简化 MSA,FAQ 与 H3 放方言问法 | voctos 同类建议,第三方 |

- 每个核心词收 MSA 与方言(埃及、沙特、黎凡特)两轨,排名当独立词跟踪(本套件口径)。
- 「打字用 MSA、语音用方言」是从业者说法,无一手研究,当假设用 GSC 的查询语言验证。

### 3.4 正字归一

- أ/إ/ا、ي/ى、ة/ه、tatweel(ـ)在关键词研究里归组。`tnkeeh` 是 PyPI 上的阿语预处理库(版本 0.0.9,取数 2026-10-21)。
- 归一只用于关键词研究。正文保留正确正字。

### 3.5 数字与日期

- 数字系统有两种:阿拉伯-印度数字 ٠-٩ 和西文数字 0-9。Unicode CLDR 的默认值不同:`ar` 与 `ar-AE` 默认 0-9(latn);`ar-SA`、`ar-EG` 默认 ٠-٩(arab)([cldr-json](https://github.com/unicode-org/cldr-json),取数 2026-10-21)。CLDR 是区域库默认值,不代表本国网站习惯。
- 本套件口径:全页统一一种,不混用。`local_format.py --market ar` 检查混用。
- 日期例:٩ أكتوبر ٢٠٢٦。电话前缀:沙特 +966、阿联酋 +971、埃及 +20(`markets.json` 目前只配 +966)。

### 3.6 文案长度

- 旧稿称阿文文案比英文长约 20%。没有一手来源,按本套件口径保留余量:title 60 字符、description 155 字符、句长 15–20 词。Google 没有 title/description 固定字符上限,按显示宽度截断。
- 实测方法:把英文版与阿文版同一页放进 `parity_check.py`,用实际比值定本站的带宽(见检查清单)。

### 3.7 3arabizi

- 罗马化阿文(3arabizi)按音译规范化聚类,与原书写体当变体归组研究(本套件口径)。

### 4.2 阿英引用池差异(第三方研究,厂商自测)

- VOCTOS(一家提供 GEO 服务的机构)的沙特医疗问题研究:40 组配对问题,同时用海湾口语阿语和英语提问 Google **AI Mode**(未登录),收集于 2026-09-09/10,共 753 条引用,配对答案的平均域名重叠 **0.149**,14/40 组零重叠。这是中期发布,面板仍在收集,作者自己写区间应当宽([研究页](https://www.voctos.com/research/arabic-vs-english-ai-citations/))。
- VOCTOS 另一项:8 组配对(共 16 个提示词),埃及住宅 IP,桌面,AI Overviews,2026-08-17。阿语 AIO 引用 44 条、无一条来自目录站或第三方榜单;英语 AIO 引用 43 条、其中 8 条来自目录站和榜单([研究页](https://www.voctos.com/blog/arabic-vs-english-ai-overview-citations/))。旧稿写「16 组」,实为 8 组配对。
- 样本小、单一机构、单次采集。结论按方向性使用:英文版被引不能推出阿语版被引,阿语 GEO 要用阿语提示单独测。

## 六、红旗与法规

- **Arabizi**:既有阿语用拉丁字母音译,也有英文品牌名打成阿文字母。当变体聚类处理,不当独立意图建页,也不当噪音丢弃(本套件口径)。
- **阿联酋广告主许可证**(UAE Media Council):依据 Federal Decree-Law 55/2023 与 Council 主席 2025 年第 3 号决定。个人在社交媒体上做广告内容,无论是否收费,都须持证;为自己或自己拥有的公司的产品在个人账号上做广告是豁免项([官方页](https://uaemc.gov.ae/en/%D8%AA%D8%B5%D8%B1%D9%8A%D8%AD-%D9%85%D8%B9%D9%84%D9%86/)、[官方指南 PDF](https://uaemc.gov.ae/wp-content/uploads/2025/08/Advertiser-Guide.pdf))。生效日:律所资料写 2026-02-01(截止日 2026-01-31);罚款「AED 10,000」只在媒体报道里见到,官方页未读到,先写「未核」。旧稿「含个人账号」说得过宽,以豁免项为准。
- **沙特 GAMR**:旧稿称上线前要过 GAMR「广告词表」。本次没找到官方词表,先写「内容标准以 GAMR 官网为准」。
- **沙特 PDPL**:Royal Decree M/19(2021-09-16),经 M/148(2023-03-27)修订,2023-09-14 生效,多数控制者有至 2024-09-14 的过渡期;监管机构是 SDAIA;境内适用,部分情形域外适用([DLA Piper 汇总](https://www.dlapiperdataprotection.com/?c=SA))。要判断是否适用,看你是否处理沙特境内个人数据。
- **阿联酋 PDPL**:Federal Decree-Law 45/2021,2022-01-02 生效;适用于全部或部分通过电子系统处理个人数据,境内外均可([u.ae 官方页](https://u.ae/en/about-the-uae/digital-uae/data/data-protection-laws))。自贸区(如 DIFC)另有法律。
- 以上是适用范围提示,不是法律意见;上线前请本地法务确认。
- **机翻镜像**:机器翻译镜像页不会因翻译而自动获得引用;VOCTOS 等从业者把它列为反模式(第三方,无对照实验)。做法:原生阿语写作,逐页比较。
- **单一「阿语市场」思维**:沙特、阿联酋、埃及用词与语域不同。内容分国时再分 hreflang(见 3.1)。
- **平台误区**:Salla、Zid 需要手动补技术 SEO 面(见二)。

### 真实站验证(youm7.com / aljazeera.net × site_audit + llmstxt check + head_check)
