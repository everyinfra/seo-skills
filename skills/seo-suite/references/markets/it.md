## 一、格局

### 1.1 引擎份额

- 数字以 StatCounter 原始 CSV 为准(`gs.statcounter.com/search-engine-market-share/all/italy`,可加 `chart.php?...&csv=1` 取月度表)。
- ANSA 引用的 90.87% 等于 StatCounter 2026-01 单月值,不是 12 个月均值。
- 手机几乎只有 Google(97.54%)。桌面 Bing 13.46% 值得做 Bing Webmaster + IndexNow;预算按设备拆分写。

### 1.2 AI Overviews 与 AI Mode 时间线

- 2025-03-25:Google 宣布 AI Overviews 进入意大利(意大利语和英语),同批有奥地利、比利时、德国、爱尔兰、波兰、葡萄牙、西班牙、瑞士。来源:`blog.google/feed/were-bringing-the-helpfulness-of-ai-overviews-to-more-countries-in-europe/`。
- SEOZoom 把 2025-03-26 记为意大利 SERP 出现首批 AIO 的日子,比博客晚一天;写日期时以 Google 博客为准。
- 2025-10-07:Google 把 AI Mode 扩到 35+ 种新语言和 40+ 个新地区,总数 200+(`blog.google/products-and-platforms/products/search/ai-mode-expands-languages-locations/`)。
- 覆盖率会随时间爬坡。任何覆盖率数字必须带「采样日期、关键词样本量、设备」。

### 1.3 覆盖率与引用集中度(SEOZoom,2025-12-02)

- 样本:约 3000 万关键词。54.15% 的查询出现 AIO。
- 被引域名约 17.5 万个,占其监测域名的 0.1%。解读:被引是少数。口径来自一家工具商的监测库,不是全网。
- 本套件做法:报告里写「SEOZoom 口径」,不与其它工具的百分比直接相减。

### 1.4 新闻出版商与监管

- 2025-10:意大利出版商联合会 FIEG 向通信监管机构 AGCOM 提交投诉,称 AI Overviews 和 AI Mode 违反《数字服务法》(DSA),Google 是「traffic killer」。同类投诉在其它欧盟国家同期提出,由欧洲报业协会(ENPA)协调。来源:The Guardian 2025-10-16。
- Google 的回应针对的是 Authoritas 和 Pew 两项研究:称它们不准确、方法有缺陷。这不是对 FIEG 流量数字的回应。
- 旧版写的「Repubblica −30%」「极端 −40–50%」「Wikipedia 暴露文章 −15%」找不到原文,已删。新闻客户用自己的 GSC 数据写降幅。

## 二、渠道

### 2.1 P.IVA 与 Registro Imprese 竞品链

- 法条:D.Lgs. 70/2003 第 7 条要求信息社会服务的提供者,以直接、永久、易取得的方式公示名称、注册地址、联系方式(含电子邮箱)、REA 或 Registro delle imprese 登记号、P.IVA(如从事应税活动)等(`parlamento.it/parlam/leggi/deleghe/03070dl.htm`,核对 2026-10-21)。
- 因此商业站页脚通常有 P.IVA 和登记号。步骤:竞品页脚 P.IVA → Registro Imprese 公开查询 → 取 ATECO 行业码(ISTAT 分类)和省份 → 同码同省企业 = 候选竞品池 → 再逐家核 SERP、外链、价格页。
- 本套件口径:这是方法,不是法律要求竞品公开 ATECO。能查到什么以 Registro Imprese 官方检索范围为准。

### 2.2 付费稿件与外链

- Google 垃圾内容政策(link spam)原文:「Buying or selling links for ranking purposes」属于链接垃圾;同一段也写明,出于广告或赞助目的的链接买卖是正常商业行为,只要用 `rel="nofollow"` 或 `rel="sponsored"` 标注就不违规(`developers.google.com/search/docs/essentials/spam-policies#link-spam`,核对 2026-10-21)。
- 同一政策把「付费文章里带优化锚文本的链接、在其它站分发的新闻稿」列为示例。
- 做法:新闻稿和付费稿只用于品牌实体占位;链接加 `rel="sponsored"`;稿件标注 publiredazionale / contenuto sponsorizzato。
- 外链台账分两列:自然获得 / 付费(已标注)。价格带旧版来自代理商价目页,无稳定一手来源,已删;报价单每次向代理索取当期书面价。

### 2.3 社区信息源

- Connect.gt(Forum GT)是意大利老牌 SEO 社区。注册人数和活跃度旧版写 13 万+,找不到原文,未核;引用其帖子前先看帖子日期。

## 三、语言机制

### 3.1 意英双轨

- 技术和潮流词常用英语借词(SEO、digital marketing、machine learning);交易和生活词用意语(prezzo、spedizione、recensioni、come fare)。
- 关键词表分两列建。借词页仍归 it-IT,不因借词多就挂 en。

### 3.2 关键词池

- 同主题意语量级与德、法不同,不按其它语言等比折算。
- 补量:问题式长尾(come / quanto costa / migliore per)+ 借词层 + it-CH。

### 3.3 语域与 locale

- Lei(商务默认)/ tu(营销口语),全站一致。【本套件口径】
- it-CH:用 `.ch` 域、CHF 报价、本地用词。hreflang 写 `it-CH`(ISO 639-1 `it` + ISO 3166-1 `CH`,合法)。同语言区域版若正文相同,Google 可能把它们当重复页并选一个规范页,所以 it-CH 页需要有真实差异(价格、地址、法律页)。【本套件口径,依据 Google localized-versions 文档对重复页的说法】

## 四、AI-GEO

- 引用面:YouTube 和 Wikipedia 居前;垂直健康站(my-personaltrainer.it、Santagostino、Humanitas)进入前十;新闻域名在 SEOZoom 文中没有单独数字。
- 点击影响的外部参照(都不是意大利数据):Pew 美国成人 900 人、68,879 次搜索,有 AI 摘要时点击传统结果链接 8%,无摘要 15%(2025-07-22);Ahrefs 2025-04 样本 30 万词,位置 1 点击低 34.5%,2026-02 更新为 58%;Seer Interactive 2025-09 更新,有 AIO 的查询自然 CTR 从 1.76% 降到 0.61%(−61%)。
- 本套件做法:用本站 GSC 的分段 CTR 写预期,外部数字只作区间参照。
- 测量:AIO 出现率抽样记录采样日期、设备、语言和是否登录;证据阶梯六级分开记(eligible → retrieved → cited → mentioned → recommended → converted),见 `content/geo-evidence.md`。

## 五、红旗

1. 直译关键词:用 Keyword Planner 或 SEOZoom 的 it-IT 数据验证,不按词典映射。
2. 把 SEOZoom 的 54% 当全行业事实:它是一家工具商监测库的结果。
3. 付费链接不标 `rel="sponsored"`。
4. 新闻客户引用他人降幅数字:没有原文就不写。
5. it-CH 复制 it-IT。
6. 评分展示「4 星比 5 星可信」:来源未核,按 A/B 测试结果决定,不当规则。

## 十、上线检查清单

| # | 检查什么 | 怎么查 | 通过 / 失败判据 |
|---|---|---|---|
| 1 | title / description 长度 | `python3 scripts/site_audit.py URL --market it` | title ≤60 字符、description 77–155 字符(本套件口径);超出为 WARN |
| 2 | head 元素 | `python3 scripts/head_check.py URL --market it` | error=0;twitter:* 与 OG 重复只是 INFO |
