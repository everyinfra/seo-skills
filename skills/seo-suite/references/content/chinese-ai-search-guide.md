# 中文 AI 搜索优化指南（数据驱动）

> 建立于 2026-10-09。实测数据来自 [liangdabiao/GEO-Content-Optimizer-Skill](https://github.com/liangdabiao/GEO-Content-Optimizer-Skill) 的 geolook 技能（CN-GEO 数据集 v2.0.1：187,818 条去重引用、12 个平台终端）；平台规则交叉自该仓库与 [flaqai/backlink_skills](https://github.com/flaqai/backlink_skills)。按本套件证据约束改写：数据为该团队自建数据集的测量结果，非引擎官方算法。
> 本文件是本套件的独有差异化：英文 SEO 技能生态没有这份数据，而我们的技能以中文为先。

## 一、引用经济学（先看这个再定预算）

基于 187,818 条去重引用的实测：

| 引用来源类型 | 占比 | 含义 |
|---|---|---|
| **品牌官网** | 仅 **1.37%**（52 域） | "官网是事实源，不是引用源"——把官网从 60 分做到 90 分，不如在排行站多赢一个条目 |
| **28 个排行/榜单站** | **9.1%**，且占据最早引用位 | 最高 ROI、最被忽视的渠道（cnpp.cn 均引位 6.10、maigoo 6.36、askci 6.27、iimedia 7.27、phb123 7.12） |
| 内容平台（qq+toutiao+baidu+iesdouyin） | 16.4% | 分属不同引擎的护城河，见下表 |

**行动含义**：外链/实体建设预算应优先投向排行站（maigoo/chnapp/cnpp/phb123 类），而非死磕官网自身。

## 三、CJK 内容阈值（可操作数字）

- **营销词密度**：创新领先/卓越/全方位/一站式/极致/颠覆/最佳 类词 **>3 个→换具体事实**。
- **句长**：理想 **15–25 字**；>25 字拆句；>35 字 AI 难以理解。
- **每页 ≥1 个直接问句**；没有数字则补行业数据或自有统计。
- **FAQ ≥10 对**、每答 80–200 字，问题用用户真会问的口语（不是营销腔）。
- 作者标记不得为"佚名/本站编辑"；需 sameAs 社交账号 + hasCredential。
- **Pillar 页 ≥1,500 字**（头四分位均值 1,943 字 vs 尾部 170 字，差 11.4 倍）；H2 ≥6；段落 ≥25；列表密度 ≥0.35。
- **JSON-LD 的 description 与品牌事实卡逐字一致**——不一致是品牌描述漂移的第一成因。

## 四、内容形态乘子（实测影响幅度）

| 形态 | 影响 |
|---|---|
| 有源数字 | **+61.6%** |
| 定义块 | +57.3% |
| 对比块 | +55.3% |
| 操作步骤 | +41.2% |
| 纯问答格式 | **−5.7%**（负） |

**一套事实三种变体**（绝不跨渠道发同文）：官网权威页（最长、带 schema 与来源表）/ 公众号版（口语标题、结论先行、短段）/ 垂直社区版（知乎体回答）。中文提示词触发的平均引用（10.41）略弱于英文（11.68）；问题必须用母语措辞——"XX 好用吗""XX 和 YY 哪个好""XX 多少钱"，绝不用翻译腔。

## 五、中文 AI 搜索就绪清单（15 项）

1. robots 未禁 Baiduspider / Bytespider / GPTBot 等；内容在静态 HTML（SPA 空壳 = P0 失败）
2. sitemap.xml + /llms.txt 存在
3. 百度双前提：百科词条 + 百家号（知道 2026-08 降级出榜，补位=什么值得买/B 站；入口=百度 App 文心助手 2.0）
4. 微信公众号活跃 + 腾讯新闻投放（元宝主通道）
5. 抖音图文/视频 + 头条号（豆包主通道）
6. 夸克/神马收录（千问通道）
7. 排行站条目：maigoo / chnapp / cnpp / phb123 至少 3 家
8. 知乎 + 技术社区（cnblogs/csdn/zol/36kr）用母语问句作答；跳过抖音 AI
9. 实体一致性：Organization JSON-LD description 与 llms.txt 与事实卡逐字一致；别名与常见错拼列入
10. CJK 格式：句 15–25 字；pillar ≥1,500 词；H2≥6；列表密度 ≥0.35
11. 可抽取块：每目标页含定义 + 2–5 个有源数字 + 对比表 + 步骤 + "不适用边界"（乘子 +41~62%）；避免纯问答排版
12. 营销词 ≤3/页；禁标题党（暴涨/封神/必看/颠覆）
13. 证据纪律：每条主张可溯源；未验证标"待确认"，绝不模型补
14. 多引擎分开采样（每引擎 × Web/App ×3–5 次，报"n=X"）；至少含豆包/Kimi/DeepSeek
15. 运营循环：周页审计 / 双周–月采样 / 季度趋势报告；AI 答案中的事实错误（错价格/错品牌）当 P0 立即处理

**注意**:早期被调研仓库多未检查 **ICP 备案**——已修正:geo-score rubric v1.1 的 `p4.cn-engines` 检查"crawlable with ICP filing and entity information complete"(满 2 分条件含备案+实体信息),本套件采纳为中文引擎就绪判据;备案状态可能影响百度系索引信任,仍建议自行补查。

## 六、生态内搜索速查(2026-10 增补;不承诺排名)

中文区的第三战场是超级 App 站内搜索——站内词表与开放网页词表**分开建**:

1. **微信搜一搜**:标题/摘要权重最高;原创标识+认证是前提;按发布时间顺序收录;选题用微信指数(官方,7/30/90 天)。搜一搜排名≈元宝引用的入口层;**公众号"入池"机制:每篇先进初始流量池,点击率/完读率/前 3 段决定是否升级流量池(矩阵号玩法的核心)**;官方 4 类禁搜行为(2025-01)。口径更新(2026-10 二轮核验):2026 公开课口径=搜一搜 **MAU 破 8 亿、日均请求 15 亿(+40%)、近 40% 新增关注来自搜索入口**(经媒体转述);2023"近八成"为旧口径保留备考。
2. **小红书**:CES 互动分=赞×1+藏×1+评×4+转×4+关×8(2026"新版流量机制"文章系数相同——Reditor;官方从未确认;**趋势=长评/深读等互动质量权重再提高**)。标题前置核心词、前 3 行植入长尾(行业共识)。登录墙导致站外 AI 引用证据薄弱——按站内搜索渠道做,不记入"AI 引用渠道"。
3. **抖音搜索**:相关性 40/互动 30/账号权重 20/时效 10(行业);图文标题文字同样进相关性;新号从月搜 1,000–5,000 的长尾词起步(行业)。
4. **知乎**:机构号+"引证"标记(官方功能:绿=有可靠来源)+结构化列表/表格。**"知乎修正"改判"引擎分化"(2026-10 二轮核验)**:geo-research 面板(2026-08)几乎不引;但 ZhiMaHang issue-11(2026-09,13,203 引)中知乎总榜 #9(221 次)、**文心 #3(156)/DeepSeek #4(65)**,阿里云 8 周实测可引——**按目标引擎分别实测,不预设**。
5. **豆包信源**:字节系双发(头条号+抖音图文);高权媒体稿收录 48h、被引 2–4 周(行业)。**2026-07 信源池改版:第三方商业站 32%→7%、字节系 >86%**(行业监测);早前"头条 35.2%/知乎 21.8%"为单源(2026-07 横评,疑同源)降级备考;issue-11 实测 2,016 引中 **iesdouyin 404 绝对主导**——抖音权重再上调。
6. **采样风控**:DeepSeek 连续约 30 问触发风控(geo-book 一手,单源);**2026-05-29 起新限制:修改/重生成上限降至专家 3 次/快速 6 次,触发后锁 10–20 分钟**(官方称算力压力)——分时段可规避(issue-11 分轮 135/135 无失败)。豆包 API 不带联网。手工采样每引擎分多时段、≤20 问/时段。
7. **内容四硬指标**(geo-book,可移植):结论前置 40–60 字;对比表 ≥5 维;价格带日期;数字可验证。
7b. **百度收录加速(2026 现役,深挖轮)**:"快速收录"已死(2024-04 下线)→"快速抓取"仅搜索资源平台 VIP;**现役三通道=普通收录 API 推送(当天新链,配额有限)/sitemap/手动提交**;WP 有"站长帮"插件实时推送,开源方案 renfei/Indexing 一键推三引擎;**蜘蛛池/泛目录只抓不录且被官方定性黑产(2026-09 实测)**。
7c. **工具圈(深挖轮)**:5118(50 亿词前 20 排名库)**已出 MCP/Skill 包(36 API 可接 Claude/OpenClaw)**;爱站/chinaz"百度权重"是第三方模拟估算非官方;**假权重识别红旗:权重词全是无人竞价的冷僻长词**。
8. **断言半衰期**:信源偏好结论 6–12 个月即可能失效(Kimi 知乎占比的三方矛盾为例)——所有引用偏好表**带测试日期**。

## 九、服务化流水线与实测增量(aigclink/geolook 深读,2026-10-09)

来源:[aigclink/geolook](https://github.com/aigclink/geolook) 全仓——SKILL.md + references/ 8 文件(method/cn-source-ranking/cn-platforms/global-platforms/content-patterns/attribution/sources)。与本文既有数据同源(CN-GEO v2.0.1 上游是 yaojingang/geo-citation-lab),以下只列此前未吸收的增量。

### 9.1 漏斗分层与"被引次数 ≠ 被采纳深度"(海外三平台,arXiv:2604.25707,测量于 2026-04)

三段漏斗:①是否触发联网检索(问题类型决定:时效/事实/决策类更易触发)→②哪些信源进引用列表(域名权威/站点类型/可抓取)→③哪些内容真被吸收进答案(对题性/长度/结构/证据密度)。

| 指标 | ChatGPT | Google AIO/Gemini | Perplexity |
|---|---:|---:|---:|
| 触发联网检索率 | 98.64% | 99.67% | 100% |
| 每 Prompt 平均引用数 | 6.88 | 12.06 | 16.35 |
| **单条引用平均影响力** | **0.2567** | 0.0455 | 0.0548 |

ChatGPT 引用最少但单条吸收深度是 Google 的 5.64x、Perplexity 的 4.68x——**被引次数与被采纳深度必须分开算指标**。策略分叉:深度采纳→ChatGPT 路径(深度定义/完整证据链);广覆盖→Perplexity 路径(一页覆盖尽量多子问题的综合长页);AIO→标题关键词对齐+显式写来源(B 层实验:要求带来源的 Prompt 引用 15.90 vs 角色型 10.40)。三平台来源类型高度集中:官网+新闻+垂类合计 ChatGPT 87.52%/Google 87.34%/Perplexity 79.12%——别在长尾杂站花预算。US 占比 82.70–86.76%、英文占比 82.90–95.07%。

### 9.2 六维体检的实测依据(国内文档此前只有阈值没有出处数字)

- **对题性是最强单因子**:`llm_relevance_score` r=0.432 > 语义相似度 0.356 > 内容质量 0.292——标题/H1/H2 含目标问题原话,不是含主题词。
- **分段影响力**:≤100 词=0.0546、1001–3000 词=0.1258、>3000 词=0.1457;**1000 词是门槛不是目标**(长度阈值 ≥1500 满分/≥1000 85%/≥600 60%/≥300 35%)。
- **页面类型影响力均值**:定义型 0.1531、对比型 0.1524、纯 reference 型 0.0529(差近 3 倍)。
- **结构四分位**:Top=10.59 标题/47.49 段/列表密度 0.428;Bottom=0.85/8.34/0.048。
- **权威门槛**:被引来源 Final_DR 中位 ChatGPT 592/Perplexity 542/Google 526;DR≥500 占 55.67–68.30%——权威度决定**有没有资格进候选池**,不自动等于高影响力。
- **可引段判据**(块级):按 H2 切段,一段"可被独立引用"= 词量 ≥60 且含至少一种硬信息(数字/定义句/操作步骤);整页 ≥3 节、≥300 词却零可引段 → NO_QUOTABLE_PASSAGE,修法=把 2–3 个核心小节改成证据段。
- **四层依赖模型**(修复顺序):访问(robots/WAF/noindex/SPA 空壳)→定向(sitemap/canonical/llms.txt)→理解(JSON-LD 与可见内容一致/原生语言)→可引用(长度/结构/抽取块);**每层依赖上一层,先修失败的最上游层**——访问层挂了,下游优化在引擎侧不可见。

### 9.3 中文引擎采样 API 实战坑(一手实测,补足第二节)

- **千问**:OpenAI 兼容端点 `/compatible-mode/v1` 即使传 `enable_search`+`search_options.forced_search` 也**不返回 `search_info`**(流式同样没有);必须走原生端点 `/api/v1/services/aigc/text-generation/generation` 才在 `output.search_info.search_results` 拿到带 `site_name` 的来源。不加 `forced_search` 时模型常用参数化知识作答(会答出"现在是 2024 年"),等于没联网。
- **豆包/火山方舟**:/chat/completions 传 `web_search` tool 报 `MissingParameter`;联网只能走 `/responses` 端点且默认 `ToolNotOpen`——**内容插件须控制台单独开通**(console.volcengine.com CC_content_plugin);开通前后是两套口径,切换当期**丢弃旧样本重设基线**;联网单次约 100 秒(千问约 9 秒),排期留足。
- **API 联网状态表**:智谱 GLM/DeepSeek/Kimi/MiniMax/Grok 的 API 均不联网(测参数化知识);Gemini OpenAI 兼容端点不带 grounding;**Perplexity API 原生联网并返回 citations(海外采样证据质量最好)**;ChatGPT 网页版/Claude 网页版/AIO/元宝/百度 AI/纳米 AI 只能人工或浏览器采。API ≠ 网页端,各占一行不合并。
- **CN-GEO 12 平台终端 code 表**(复算口径):DP/DPA(DeepSeek web/App)、DB/DOUBA(豆包)、TYQW/TYQWA(千问)、TXYB/TXYBA(元宝)、KIMI、BDAI(百度 AI)、WXYY(文心)、DYAI(抖音 AI)。
- **数据边界**(上游自陈):CN-GEO 原始层缺完整回答/批次/模型版本/采集时间——**来源覆盖与跨平台共识可直接用,趋势/情感/品牌推荐率不能**;是静态快照非实时监控。复算:geo-citation-lab `source_visibility.parquet`(duckdb,字段 deduplicated_citation_count/average_quote_position)。

### 9.4 采样环境四档与证据分级(比"多引擎×3-5 次"更细的纪律)

- **采样环境四档**:sandbox(一次性无 Cookie,免登录引擎首选)/incognito/clean_profile(专用采样 Profile,从不搜自己品牌、关个性化;适用须登录的豆包/Kimi/元宝/ChatGPT)= A 级;**personal(个人日常账号)自动降 D 级**——测的是"AI 对你的画像",不能当可见性证据。样本记 `session_mode`。
- **证据等级**:A=人工/浏览器真实样本(有原文+来源链接+环境记录)/B=API 可复现(注明是否联网)/C=合成演示/D=待复核。没有答案原文/截图/环境记录的不许标"真实采样"。
- 每题新开对话(上下文带偏置);没提到品牌也照记("没提到"正是最重要数据);轻量周检=只查买家意图题(推荐/比较/替代/价格)每引擎 ≈半小时,全量留正式采样。机器判读是正则——品牌撞词/否定语境/竞品别名会误判,人工纠正打 `manual_override` 重跑不覆盖。
- **意图三分**:买家意图(推荐/比较/替代/价格,离成交最近优先补)/需求教育(场景/风险)/探测(品牌验证——点名题答案必复述品牌名,**单独归"品牌认知",不计入可见性指标**)。问题库七组各 3–6 题且每题标 market 路由。

### 9.6 内容与工单模板增量

- **榜单页必须先写评选方法**(维度/权重/数据来源/利益披露)再给榜单——"没有方法论的榜单在 AI 眼里就是软文"。标题用用户原话:"2026 年 <品类> 怎么选?N 款主流方案对比"。
- **对比页规则**:同口径 6–10 维度(不能给自己加独有维度)、**必须写自己的局限**(只夸自己的对比页可信度极低)、每结论挂来源、结尾给决策树("如果你是 X 且看重 Y→选 Z")。
- **品牌事实卡证据等级 A–E**(A 官方已证实/B 第三方可佐证/C 内部待授权/D 需补证/E 禁止使用;D/E 必须有处理动作);自动推导的事实抽不到一律标"待确认",绝不用常识填充。
- **优先级×风险双轴**:P0 门票(robots/SPA 空壳/无 sitemap)→P0 事实错误(品牌被说错/价格错/归错行业)→P1 抽取块缺口→P1 高价值问题无承接→**P1 外部信源(不是 P2——官网只占 1.37%)**→P2 长尾。风险独立分级:低风险(纯新增资产先做建立信任)/内容调整(发布后 7/14/28 天各复核)/高风险技术改造(动 robots/WAF/noindex——P0 也是高风险,改错一行封全站;备份+小批量+回滚+改后立即重跑体检)。
- **保护性纪律**:先保护已有 URL/canonical/标题历史权重再新增;禁止一次性批量改已收录页;**sitemap 只装值得被引用的规范页**,站内搜索/带参/翻页 URL 用 robots 挡(`Disallow: /search?`、`Disallow: /*?session=`)——低价值页进检索索引会稀释实体表征。
- **无官网项目模式**(电商商品/线下品牌/小程序):技术体检跳过、llms.txt/JSON-LD 不产出(需自有域名)、**引用官网率显示"不适用"而不是 0**;采样/竞品/阵地/工单照常——AI 可见性本来就主要靠外部阵地。
- **robots 判定须按 RFC 9309 语义,逐行正则会漏三种真实封禁**:①`*` 组 Disallow 全站封掉所有无专属组的 AI 爬虫(最常见无意封禁);②多 UA 行共享一组规则,逐行正则会把第一个 UA 判成空规则;③专属组存在时通配符组整组失效(不看顺序)。
- 节奏:页面体检每周/答案采样每两周或每月(采样有成本+指标有噪声,跑太密看不出信号);无官网与双市场竞品清单分开(漏真实对手会高估名次)。
- 上游生态:数据=yaojingang/geo-citation-lab(海外 01 实验报告/国内 03 数据集/54 篇论文库);海外三平台论文 arXiv:2604.25707、中文四产品八界面论文 arXiv:2607.15771;姊妹工具 GEORank(自托管工作台)/GEOFlow(规模化生产分发)。

## GEOrank 自托管工作台的五件套与 30/60/90 方案生成(GEORank 深读 2026-10-09d)

来源:[yaojingang/GEORank](https://github.com/yaojingang/GEORank) `README.md` + `skills/georank/`(SKILL/references)+ `cli/georank_cli/`。把上文"姊妹工具 GEORank"展开:它是面向 GEO 的开源工作台(monorepo:静态前台+Next.js 管理台+FastAPI/Celery 后端;数据面 PostgreSQL/Redis/Qdrant/Neo4j/MinIO——**检索底座是向量+图谱双库**),工作流七步:发现→诊断→问答→规划→拓展→结构化→管理。

**GEO 工具五件套**(README「GEO 工具」行原文清单):

| 工具 | 作用 | 与本指南的对应 |
|---|---|---|
| JSON-LD 生成器 | 结构化标记产出 | 上文 schema 体检的修复出口 |
| llms.txt 生成器 | AI 抓取摘要文件 | 见 llms-txt 指南 |
| AI 友好度评分 | 站点对 AI 摘要/引用的适配打分 | 与页面体检表互补的自动化版 |
| GEO 标题生成器 | 面向 AI 引用的标题改写 | 上文"标题用用户原话"规则的工具化 |
| 知识库生成器 | 把关键词/问答/教程沉淀为可复用资产 | 对应"资产化/阵地沉淀"环节 |

诊断维度官方口径:Schema、页面结构、Meta 信息、内容可读性、引用信号、AI 搜索可见性;拓词工作台从业务词扩**问题词/场景词/商业意图词/推荐型词**。API 面(FastAPI):`POST /api/companies/submit`(提交即触发抓取+AI 分析)、`POST /api/diagnostics/`(返回 report_id,轮询 pipeline-status)、`POST /api/solutions/chat`、`POST /api/keywords/expand`;配套 CLI 是 typer 骨架(auth login / company submit / diagnostic run 三命令)。运维 Skill 的安全设计值得抄:**登录永不传角色**、`/api/auth/me` 是唯一角色权威、写操作默认 dry-run 须 `--execute`、管理员写加 `APPLY_ADMIN_CHANGE`、删除加 `DELETE:<精确路径>` 确认短语、密钥只走隐藏输入/环境变量/文件不进 argv。

**30/60/90 增量**:README 的 GEO 方案模块按"目标、网站、资源、限制条件"四输入生成 30/60/90 天计划(仓库未公开计划内文);结合其工作流七步与本指南的 P0→P2 优先级轴,映射如下——**30 天(诊断+门票)**:跑网站诊断六维、修 P0 门票(robots/SPA 空壳/sitemap)与 P0 事实错误,用五件套先产出 JSON-LD+llms.txt 两类低风险新增资产;**60 天(承接+外部)**:补 P1 抽取块缺口、为高价值问题建承接页,拓词工作台扩问题词/场景词并转内容选题,启动外部信源建设(官网只占 1.37%,外部信源是 P1 不是 P2);**90 天(资产化+复诊)**:知识库生成器沉淀问答与教程为长期资产,答案采样对比 30 天基线,把诊断-方案循环固化为季度节奏。三档共同纪律:高风险技术改造(动 robots/noindex)即使 P0 也要备份+小批量+回滚,改后立即重跑体检。
